# 영어용사: 잃어버린 언령의 서 — 구현 계획

코드용사(2D), 수학용사(3D)에 이은 용사 3부작의 세 번째. HD-2D(3D 무대 + 2D 도트 빌보드) 턴제 RPG.
초등 3~6학년, 2022 개정 영어과 교육과정 연계.

## 1. 확정한 결정

| 항목 | 결정 |
|---|---|
| 게임 구조 | 자유 탐험 필드(마을·필드·던전) + 보이는 적과 닿으면 턴제 전투 무대로 전환 |
| 전투 | 직업을 가진 파티의 턴제 RPG. 덱·손패 없음 |
| 학년 | 시작할 때 3~6학년 선택, 메뉴에서 언제든 변경. 이야기와 시스템은 같고 낱말·문장·보조 표시만 다름 |
| 기술 구성 | 빌드 없는 순수 ES 모듈 + three.js. UI는 HTML/CSS |
| 맵 | 글자 격자 타일맵. 구역 단위로 나눠 문으로 잇기 |
| 판정 | 낱말 속성 표시 규칙 + 숨은 특별 조합 일부 |
| 어휘 | 교육과정 초등 권장 어휘 중심, 판타지 낱말은 소수이며 도감에서 '모험 낱말'로 구분 |
| 발음 | 미리 만든 음성 파일. 필살기는 리듬 영창이 기본, 마이크 음성 인식은 나중에 선택 기능 |
| 그림 | 일러스트(설정화·전신·상반신)는 외부 생성, 도트 스프라이트는 저장소에서 직접 제작. `docs/art-request.md` |
| 낱말 아이콘 | 전투용 약 50개는 직접 제작, 나머지는 외부 생성 후 일괄로 색 수·격자 정리 |
| 저장 | 기기 저장(localStorage) + 파일 백업. 이어하기 코드·학급·교사 화면은 본편 뒤 |
| 주인공 | 고정 인물 2명(마루, 소리) 중 선택. 고르지 않은 쪽은 이야기 속 라이벌 겸 조력자 |
| 배포 | Cloudflare Workers 정적 자산, GitHub 푸시 자동 배포, ssamflow 하위 도메인 |

## 2. 파티와 직업

모든 인물이 자기 무기와 자기 동사로 공격한다. 직업은 잘 다루는 문장 자리가 다르다.

| 인물 | 직업 | 합류 | 무기·기본 공격 | 특기 자리 | 전투 역할 | 필드 행동 |
|---|---|---|---|---|---|---|
| 마루/소리 | 견습 마검사 | 처음 | 검 `Cut` | 동사 | 단일 대상 물리 | Name: 이름 붙이기 |
| 무지 | 색채 마법사 | 월드 1 | 지팡이 `Burn` `Freeze` | 형용사 | 속성 공격, 부여 | Look: 살펴 묘사 얻기 |
| 나루 | 길잡이 궁수 | 월드 2 | 활 `Shoot` | 전치사 | 범위·대상 지정 | Find: 힌트대로 찾기 |
| 가락 | 음유시인 | 월드 2 | 악기 `Sing` `Play` | 질문·감정 | 전체 공격, 회복, 교란 | Ask: 묻기 |
| 도담 | 고서 학자 | 월드 3 | 마도서 `Write` `Read` | 비교급·시제 | 증폭, 맞불, 예약 | Read: 해독 |
| 두둑 | 떠돌이 상인 | 월드 4 (월드 2부터 가게 주인으로 등장) | 주머니 `Throw` | 수·물건 | 다단 타격, 아이템 | Bargain: 흥정 |

전투 출전은 4명. 월드 4 후반에 코드용사·수학용사가 손님으로 나온다.

## 3. 전투

### 명령이 곧 문장

| RPG 조작 | 문장의 자리 |
|---|---|
| 기술 고르기 | 동사 |
| 속성 붙이기 | 형용사 |
| 대상 지정 | 명사 (적·사물 머리 위 영어 이름표를 누름) |
| 위치·범위 지정 | 전치사구 |

### 한 턴

1. 화면 위 행동 순서대로 차례가 온다.
2. 명령 메뉴: 기술 / 말 걸기 / 아이템 / 방어.
3. 기술을 고르면 문장 틀이 열리고 자리를 채운다.
4. 목소리 칸을 쓰면 문장에 자리가 늘어난다. `Cut the wolf` → `Cut the cold wolf` → `Cut the cold wolf behind the rock`
5. 완성 문장이 크게 뜨고 음성으로 읽힌 뒤 연출.
6. 판정 후 다음 차례. 적도 영어 기술명을 외치며 행동한다.

### 판정

- 피해 = 공격력 × 기술 위력 × 상성 배율 × 목소리 배율 − 방어력
- 상성은 두 갈래: 무기(동사) 상성, 속성(형용사) 상성. 약점 1.5배, 저항 0.5배, 겹침 가능.
- **침묵의 방패**: 적마다 방패 수치와 숨은 약점 칸을 가진다. 약점을 찌른 타격 한 번마다 1 깎인다.
- **깨뜨림**: 방패 0이면 적은 다음 차례를 잃고 받는 피해 2배.
- **합동 언령**: 깨뜨린 순간 파티가 한 문장을 나눠 외치는 필살기. 리듬 영창 입력.
- 말이 안 되는 문장은 실패가 아니라 웃긴 연출과 약한 효과.

### 직업 고유 장치

- 궁수: 전치사가 사격 방식. `behind` 뒷줄·숨은 적, `between` 두 적 동시, `under` 방패 무시, `next to` 옆으로 번짐.
- 음유시인: 질문으로 약점 공개, 적 상태 변화(`Are you tired?` 늦추기, `Are you angry?` 공격↑ 방어↓), 보스의 다음 기술 미리 듣기.
- 학자: 아군의 직전 속성을 비교급으로 재현(`Colder!`), 적 강화에 맞불(`bigger`), `will` 예약 공격, 과거형으로 지난 기술 재발동.
- 상인: 숫자만큼 타격, 아이템 기술.
- 보스전: 보스의 대사 속 낱말을 낚아채 쓰는 메아리 장치. 월드 3 보스는 금지문 규칙을 건다.

### 이야기 진행에 따른 확장

| 월드 | 문장 자리 | 새 장치 |
|---|---|---|
| 1 시작의 숲 | 동사 + 명사, 형용사 | 약점, 방패, 깨뜨림 |
| 2 메아리의 마을 | 3자리 | 전치사 범위, 질문, 합동 언령 |
| 3 시간의 사막 | 3자리 + 부정·시제 | 금지문 보스, 예약 공격 |
| 4 바벨의 마왕성 | 4자리 | 비교급 맞불, 최종 심문 |

## 4. 학년에 따른 차이

시스템, 조작, 수치 규칙은 전 학년 동일. 내용만 바뀐다.

- 문장 틀 자리에 후보로 나오는 낱말의 범위
- 이름표, 적 대사, 약점 힌트, 의뢰문: 3~4학년군용과 5~6학년군용 2벌
- 보조 표시(그림, 우리말 뜻, 자동 발음)를 항상 보일지 눌러야 보일지: 학년별 설정표 한 장
- 정답률에 따라 보조를 한 단계 자동 조절
- 적 체력 등 수치 난이도(쉬움/보통/어려움)는 학년과 별개 설정

3~4학년 모드에서 월드 3~4의 문법 장치는 낱말 수준으로 낮춘다(`No red!` + 그림).
교육과정 연계로 표기하는 범위: 3~4학년 모드는 월드 1~2, 5~6학년 모드는 전체.

## 5. 어휘 습득

1. **이름 되찾기**: 이름을 잃은 사물·주민은 회색 실루엣과 `???`. Name → 발음 듣기 → 음소 크리스탈로 철자 맞추기 → 색과 이름표 회복. 마을을 되찾으면 주민이 말하고 가게가 열린다.
2. **소재별 장소**: 집(가족·물건·신체), 시장(음식·수·가격), 학교·도서관(학용품·요일), 농장·숲(동물·자연·날씨), 광장·항구(직업·탈것·방향), 여관·축제(감정·취미·시간·계절).
3. **의뢰와 필드 행동**: 주민 의뢰, 요일·날씨가 흐르는 세계, 직업별 필드 행동으로 낱말을 실제로 사용.
4. **전투 연결**: 음식은 회복, 동물은 소환, 날씨는 전장 효과. 전투와 안 맞는 낱말은 넣지 않는다. 기능어는 문장 틀 안 노출.
5. **언령 마도서**: 낱말 3단계(만남 → 되찾음 → 내 것). 오래 안 쓴 낱말은 빛이 바래고 여관에서 되살리는 짧은 복습. 소재별 진척도, 자주 틀린 낱말.
6. **대장간**: 긴 철자와 이중 글자 낱말을 연성하는 곳.

한계: 그림으로 표현하기 어려운 추상어는 수집 대상에서 빼고 대사 노출로 다룬다. 도감에 권장 어휘 중 다루는 수를 표시한다. 리듬 영창은 실제 발화를 확인하지 못한다.

## 7. 그림과 소리

- 도트 스프라이트: 팔레트 글자 격자(코드용사 `js/gfx/pixel.js` 방식 발전). 인물 약 32 × 48칸, 색 12~16개.
- 부위 분리(몸·머리·머리카락·망토·무기)로 걷기 4프레임 외 동작은 부위 이동으로 제작. 속성 부여와 피격은 팔레트 교체.
- 주요 인물은 공들이고, 일반 몬스터는 2~3프레임에 색 변종.
- 형용사 연출: 크기 조절, 색 덧씌움, 입자, 화면 흔들림을 모듈로.
- 음성: 낱말·기술 문장·대사를 표에서 일괄 생성해 파일로 저장.
- 효과음: CC0 음원. 배경 음악은 전작과 같은 방식으로 마련.

## 8. 단계

### 0단계: 뼈대와 자료 (지금)
- 저장소 구조, 배포 설정, 도트 도구 이식
- 낱말 데이터 표 초안(전투용 약 50개), 외부 그림 1차 의뢰

### 1단계: 전투 프로토타입
- HD-2D 전투 무대(바닥, 조명, 빌보드, 피사계 심도)
- 마검사 + 색채 마법사 + 궁수, 인물당 기술 3개, 적 2종
- 문장 틀 UI, 목소리, 동사·형용사 상성, 전치사 범위, 방패와 깨뜨림, 음성 재생
- 검증할 것: 문장으로 명령하는 전투가 재미있는가, 3학년이 조작을 따라오는가

### 2단계: 월드 1
- 타일맵 엔진, 필드 이동, 적 접촉 전환
- 이름 되찾기와 철자 맞추기, 마도서, 저장
- 마을 하나, 숲 필드, 던전, 보스. 주인공 선택과 프롤로그
- 학년 설정과 보조 자동 조절

### 3단계: 월드 2
- 궁수·음유시인 합류 이야기, 필드 행동(Find, Ask), 의뢰, 요일·날씨, 합동 언령과 리듬 영창, 흥정 가게

### 4단계: 월드 3~4와 엔딩
- 학자·상인, 금지문 보스, 시제, 비교급 맞불, 전작 용사 등장, 최종전, 엔딩

### 5단계: 다듬기와 공개
- SsamFlow 디자인 기준, 이어하기 코드, 학급·교사 화면, 약관·처리방침, 선택 기능인 음성 인식, SsamFlow 등록
